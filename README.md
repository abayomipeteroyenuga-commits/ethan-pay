# Ethan Pay v1.0
Platform code: ETH-PAY
Planned domain: pay.ethandigitalacademy.org

Professional front-end foundation for Ethan Digital Academy's central payment portal.

Current v1 functions:
- service/payment selection
- four-currency display
- preview payment references
- bank-payment submission preview
- local payment history
- local reference verification
- responsive interface
- Ethan ID sign-in placeholder for later ecosystem integration

Security / production note:
No real gateway, wallet, bank API, secret key, card handling, or cloud approval is enabled in this build. Do not collect real card details in the front-end. Payment gateway verification and Ethan ID should be implemented server-side during integration.
